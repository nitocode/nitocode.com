# nitocode.com

Site vitrine de Nitocode : une page statique (`index.html`), hébergée gratuitement par GitHub Pages.

- Images dans `img/`, issues du kit de marque (`nitocode-hq/marque/kit/`).
- `CNAME` : le domaine nitocode.com.
- Pour modifier : éditer `index.html`, pousser sur `main`, en ligne en ~1 minute.
